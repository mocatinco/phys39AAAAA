module 1: First Contact With The Instrument
In this lab, changing LED brightness via PWM was explored. 
Firstly, we explored how to make an LED blink using Arduino. Then, we introduced a potientiometer into the picture to better control the speed of blinking. Finally, by adding PWM into the picture, we were able to take the averaged ADC 10-bit number from the pot voltage and map it o the PWM 8-bit number to control LED brightness.
